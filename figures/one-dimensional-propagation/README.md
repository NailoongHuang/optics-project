# 一维波包传播动画

四个 GIF 使用完全相同的初始波包，只改变色散关系。左图显示固定坐标中的运动，右图跟随波包中心，方便观察变形。彩色线是真实计算的强度；灰色虚线是初始强度轮廓平移后的参考。

| 动画 | 色散 | 结果 |
| --- | --- | --- |
| [01_linear.gif](01_linear.gif) | ω=4+k | 匀速平移，形状不变 |
| [02_quadratic.gif](02_quadratic.gif) | ω=4+k+0.5k² | 移动并明显展宽，峰值下降 |
| [03_inflection.gif](03_inflection.gif) | ω=4+sin(k) | 中心波数 k=0 的曲率虽为零，仍发生拖尾和振荡 |
| [04_local_linear.gif](04_local_linear.gif) | ω=4+k+0.25[max(|k|−2.4,0)]⁴ | 初始频谱完全位于直线段内，和全直线例相同地传播 |

计算采用 ψ(x,t)=F⁻¹[A(k)exp(−iω(k)t)]，直接使用每个 Fourier 模式的时间相位，没有时间步进误差。初始频谱在 |k|<2.2 内为 exp[−1/(1−(k/2.2)²)]，其他波数处为零，并归一化总强度为 1。它是光滑紧支撑频谱，对应有限总强度和有限均方宽度的局域波包。未采用硬截断的矩形频谱。

全部坐标与时间均为无量纲。显示强度统一除以初始峰值；不对每帧重新归一化峰值。动画右上角的“宽度”指均方根宽度。动画播放 t=0 到 t=18，末帧停留后重新开始；循环重播不是物理复现。

FFT 计算区域长度为 512，网格点数 8192。已检查总强度守恒、将网格点数加倍、将计算区域长度及点数同时加倍、远端边界质量，以及直线例与解析平移的重合。详细结果保存在 [checks.json](checks.json)。这些动画是线性模型的数值演示，不是实际材料实验，也不以有限时间动画代替无限时间的数学证明。

复现命令：`python figures/one-dimensional-propagation/animate_packets.py`，从项目根目录运行。源代码：[animate_packets.py](animate_packets.py)。
