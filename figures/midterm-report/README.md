## 统一物理约定

模型为自旋1/2、均匀最近邻铁磁交换、零外场。原始理论来源是 [单磁子推导](../../Note/single_magnon_derivation/main.tex)；计算的色散函数复用 [现有模型](../../code/spin_wave_2d.py) 的 `Params(S=0.5, h=0)`。

位置以晶格常数a为单位；q=ka，τ=Jx·t/ℏ，η=Jy/Jx，激发能以Jx为单位。每个传播态都归一化为一个磁子，P=|ψ|²表示翻转概率。去除E_F带来的公共相位不改变任何概率。沿+x极化时，局域纵向自旋为〈Sx〉=1/2−P；固定单磁子数态的横向自旋期望为零。

Gaussian的sigma指**初始概率的RMS宽度**，振幅包络写成exp[−nx²/(4 sigma_x²)−ny²/(4 sigma_y²)]。位置图和波矢图均说明归一化方式。共动轮廓使用实际谱平均速度；中心波矢处的群速度只作为窄带近似。C13的复态重合度包含相位变化，不等同于单独比较概率形状。

## 模拟与图像的读取方法

- 动力学采用完整余弦色散的FFT谱演化，没有时间步进误差；帧间隔只决定动画采样。
- 周期晶格只是数值实现。主图在边界影响可忽略的时间范围内展示，并记录边缘概率和更大晶格的对照。
- 同一对照图和动画使用固定纵轴或色标，不逐帧放大峰值。对数色标会显露很小的概率尾部，图中已注明。
- 单点激发的主要传播前沿由最大群速度解释，前沿之外仍有小尾部。
- 等方交换的正方晶格在大波矢处仍保留晶格各向异性；只有长波极限近似旋转对称。
- 延伸图的结论是有限时间内减慢形变，不是永久保形，也不构成材料实验验证。

## 数值核验

原模型的10项回归检查全部通过。新增的[独立数值检查](checks_independent.json)包含27组案例：独立逐键构造的稀疏Hamiltonian指数推进、完整复振幅Bessel传播核、零模式、平面波、Gaussian解析矩及扩大晶格比较。稀疏矩阵对照L2误差为3.4×10⁻¹⁵；Gaussian独立控制的扩大晶格L2差最大约1.0×10⁻¹⁴。

各图组还保存自身检查：[A组](checks_a.json)、[B组](checks_b.json)、[C组](checks_c.json)。这些记录包括实际参数范围、FFT范数、边缘概率、解析结果与导出文件等。审查另独立检查了椭圆Gaussian的轴与宽度约定。[导出核验](checks_exports.json)覆盖39张静态图、528个GIF帧和40页PDF；[最终视觉与交互记录](QA.md)记录逐图、逐页和浏览器检查。

较宽且高速的Gaussian在N=256、sigma=10、q0=(π/2,π/2)、τ=60的一次验证预跑中出现4.1×10⁻⁸的边缘概率，已将该独立验证扩大为N=384并与N=768比较。该记录保存在`checks_independent.json`，没有把有限边界误差当成物理展宽。

## 复现与修改

从项目根目录运行：

```powershell
python figures/midterm-report/build_all.py
```

这个命令依次运行原模型测试、独立数值核验、三组绘图脚本，再重建离线图库和PDF，并解码、渲染所有导出文件。实际使用的软件版本及文件SHA-256见 [package_manifest.json](package_manifest.json)。主要依赖为NumPy、SciPy、Matplotlib、Pillow和PyMuPDF；中文字体使用Windows的Microsoft YaHei。计算是确定性的；唯一随机矩阵测试的种子为20261019。

需要只修改一组图时，可单独运行：

```powershell
python figures/midterm-report/generate_dispersion.py
python figures/midterm-report/generate_local_flip.py
python figures/midterm-report/generate_gaussian.py
python figures/midterm-report/build_catalog.py
```

脚本中的参数、图组manifest和保存的NPZ数据一起构成复现记录。共同模型与绘图函数位于 [common.py](common.py)。原有讲义、旧动画与历史脚本保留在原位置；本次新增成果集中在当前目录。
