统一约定
ε / Jx = 1 − cos qx + η(1 − cos qy)
q = ka，τ = Jxt / ℏ，η = Jy / Jx。位置以晶格常数 a 为单位。所有传播态满足 ΣP = 1，P = |ψ|² 表示翻转概率；σ 是初始概率的均方根宽度。

a01-lattice基础
